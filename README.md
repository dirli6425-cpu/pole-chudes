МИЛЛИОН ДЛЯ ГРУППЫ — версия 8.2

ИСПРАВЛЕНО:
1) Денежная лестница зависит только от правильных ответов команды в текущем раунде. Неправильный ответ не продвигает её.
2) У двух команд отдельные независимые подсказки: 50/50 и помощь зала (по одной каждой команде на всю игру).
3) «Звонок другу» удалён.
4) Лестница показывает текущую команду и количество её правильных ответов из общего числа вопросов этой команды в раунде. Количество ступеней зависит от числа вопросов команды в раунде (10 или 15 по сценарию); один правильный ответ — одна ступень, неверный — никакого изменения. Максимальная ступень раунда подписана 1 миллион.
5) Все 90 вопросов, 4 раунда, музыка заставки, D1 и «Поле чудес» не изменены.
