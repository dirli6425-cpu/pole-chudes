# Поле чудес — химия и строительство

Статический сайт для Cloudflare Pages. 5 редактируемых туров, алфавит, автоматическая проверка букв, полноэкранный режим.

## Публикация

Загрузите `index.html` в корень репозитория GitHub `pole-chudes`. В Cloudflare: Workers & Pages → Create → Pages → Connect to Git → выберите репозиторий. Framework preset: None, Build command: пусто, Build output directory: `/`.

## Настройки

Кнопка «Настройки» позволяет менять вопросы и ответы. Они сохраняются только в localStorage браузера, не в GitHub и не в Cloudflare. Не очищайте данные сайта, если хотите их сохранить.
