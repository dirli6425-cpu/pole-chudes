МИЛЛИОН ДЛЯ ГРУППЫ — TV STUDIO 8.1

Что нового
- Новый титульный экран: вращающиеся световые кольца, прожекторы, эмблема, группы и четыре тематики раундов.
- В комплекте авторская ~27-секундная оркестрово-электронная музыка для заставки, зацикленная до начала игры: public/million/audio/million-intro.mp3.
- Кнопка «Включить музыку» на титульнике. Она необходима из-за браузерных ограничений на автоматическое воспроизведение звука.
- Можно выбрать СВОЙ MP3/WAV/OGG с титульника. Он сохраняется локально в IndexedDB в браузере конкретного компьютера (не в Cloudflare D1 и не на других компьютерах). Максимум 25 МБ. Для точного саундтрека передачи загрузите собственную правомерно используемую запись.
- Регулятор громкости; при входе в игру музыка плавно затихает, появляется короткая анимированная заставка «Игра начинается».
- Оптимизация титульного и игрового экранов под проектор 1920×1080 и 1366×768; проверена и мобильная ширина 390 пикселей.
- Лестница показывается по текущему раунду, а не «застывает» после 15-го вопроса.
- Исправлена задержка отображения начисленного команде балла после правильного ответа.
- 90 вопросов, чередование 2 команд, 4 раунда, подсказки и загрузка из сценария — сохранены; игра «Поле чудес» не менялась.

ВАЖНО: это НЕ официальная музыкальная тема телепередачи, а новая авторская композиция в телевизионной манере. Официальный саундтрек в архив не включён.

Публикация
1. Загрузите ВСЁ содержимое ZIP в корень GitHub-репозитория вместо старых файлов.
2. Cloudflare деплой как и прежде:
   npx wrangler d1 migrations apply pole-chudes-db --remote && npx wrangler deploy --config wrangler.toml
3. Откройте /million/ и обновите страницу (Ctrl+F5 при необходимости).
4. На титульнике нажмите «Включить музыку» и проверьте громкость на колонках.
5. Если вопросы ещё не загружены в D1: «Вопросы» → «Вписать все 90 вопросов из сценария» → «Сохранить в D1».

Проверка
- JavaScript проверен node --check.
- В Chromium протестированы титульник 1920×1080, 1366×768, 390×844, воспроизведение MP3 по нажатию, остановка при старте и переход к первому вопросу.
- Проверена выдача балла после ответа и переход хода к команде № 2.
- Сама Cloudflare-публикация не выполнялась.
