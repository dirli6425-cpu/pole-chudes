# Поле чудес — химия и строительство

Статический сайт для Cloudflare Workers Static Assets / Cloudflare Pages.

## Возможности
- Титульный экран с тематическими иллюстрациями лаборатории и стройки
- Пять редактируемых туров, вопросы над словом
- Алфавит, открытие букв и сообщения об ошибке
- Финальный экран и полноэкранный режим
- Сохранение заданий в localStorage браузера

## Публикация
Загрузите `index.html`, `studio.svg`, `chemistry.svg`, `construction.svg` в корень GitHub-репозитория.
Для существующего Worker используйте deploy command:

`npx wrangler deploy --name pole-chudes --assets . --compatibility-date 2026-10-06`

Сайт не использует серверную базу данных: настройки вопросов сохраняются только на конкретном устройстве и в конкретном браузере.
