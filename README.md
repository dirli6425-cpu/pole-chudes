Версия 7.5 — настоящий барабан в классе. Игровой экран без виртуального барабана: крупные вопрос/слово/счёт и алфавит справа. Быстрые кнопки баллов, ручной пульт звуков (приз, ход, плюс, шкатулки, вращение и др.), отмена последней буквы. Заставка с декоративным вращающимся барабаном сохранена. Все пять туров и настройки D1 сохранены. На проекторе целевой размер 1920×1080 без прокрутки; на телефоне адаптивная компоновка с прокруткой по необходимости. Для внесения заданий в существующую базу: Настройки -> Вставить 5 вопросов с фотографий -> Сохранить.
