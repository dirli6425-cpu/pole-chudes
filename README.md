# Игровая студия v5.8

- `/` — выбор игр
- `/pole-chudes/` — прежнее Поле чудес (D1 `game_config`, без изменений)
- `/million/` — Миллион для группы (D1 `million_config`, редактирование и подсказки)

Деплой: `npx wrangler d1 migrations apply pole-chudes-db --remote && npx wrangler deploy --config wrangler.toml`

**Важно:** сначала применить миграцию `0002_million.sql`; она создаёт новую таблицу, не удаляет прежние вопросы. Общий `ADMIN_KEY` и cookie для обоих редакторов. Игра «Миллион» пока содержит три демонстрационных вопроса; позже их можно заменить в настройках.

Подсказка «Помощь зала» — демонстрационная симуляция, не реальные голоса. Игровой прогресс «Миллиона» живёт в текущей вкладке, а вопросы — в D1.
