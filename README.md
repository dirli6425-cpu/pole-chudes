# Игровая студия — Поле чудес 7.0

## Что добавлено
- Реальный 20-секторный барабан SVG с 6–8 полными оборотами и плавной остановкой за 6,6 секунды. Сектор выбирается криптографическим случайным числом браузера, вращение доводится до него по индикатору сверху.
- Сектора: 100–800 очков (очки × число угаданных букв), ПЛЮС (бесплатная буква), ×2 (800 очков за каждую букву), ПРИЗ, ЦВЕТЫ, ПЕЧЕНЬЕ, ШКАТУЛКИ (одна из двух — 2000 очков), ХОД (переход хода), БАНКРОТ (обнуляет счёт текущей группы, ход дальше).
- Три группы: выбор активной группы, счёт и подарки каждой; автоматическая передача хода на неправильной букве и специальных секторах.
- Буквы недоступны до остановки на секторе «очки», «×2» или «ПЛЮС». Во время вращения повторное нажатие не сработает.
- Реальные звуки пользователя: вращение барабана, правильно угаданная буква, переход хода, плюс, призы, пустая шкатулка и шкатулка с деньгами. Вручение подарков автоматически вызывает звук приза.
- Полный игровой экран и мобильная адаптация; контроль ведущего (смена группы, передача хода, открыть слово), модальные окна для шкатулок и призов.
- Автосохранение результатов в localStorage данного браузера, вопросы и группы в существующей Cloudflare D1. Резервная копия содержит очки, подарки и ход игры.

## Важные ограничения
- Реальных физических призов сайт не предоставляет: цветы, печенье, шкатулки и главный приз готовит организатор, а ведущий подтверждает вручение.
- Музыка использует файлы MP3, переданные организатором. Для воспроизведения на телефоне/браузере звук должен быть разрешён; нажатие на «Вращать барабан» инициирует старт звука.
- Данные счёта локальны для конкретного браузера и не синхронизируются между несколькими устройствами. Вопросы и группы сохраняются в D1.
- Другая игра «Миллион для группы», авторизация, Workers API и миграции не изменялись.

## Развёртывание
Замените содержимое репозитория файлами этого архива. Команда сборки Cloudflare:
`npx wrangler d1 migrations apply pole-chudes-db --remote && npx wrangler deploy --config wrangler.toml`

Игра: `/pole-chudes/`. Настройки: кнопка «Настройки» на странице.
