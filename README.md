# Миллион для группы — Studio V9 (`/site3`)

Готовые исходники фронтенда и адаптер Node.js (`.mjs`) для **существующего** Linux-сервера `games-local.service`. Не требует `server.py` и не перезаписывает текущую SQLite-базу.

## Важное: это дополнение к существующему серверу

`server.mjs` использует уже установленные у тебя файлы `/opt/games-local/local/db.mjs` и `/opt/games-local/local/worker.mjs`. Они **не входят** в ZIP и **не заменяются**. Поэтому на абсолютно пустом сервере без них проект одним кликом не запускается.

- `/site2/` — прежнее «Поле чудес» без изменений.
- `/site3/` — «Миллион для группы» V9: сценарии, звуки, состояние, SQLite.
- `/site3/api/million` — вопросы из существующей `million_config`.
- `/site3/api/settings`, `/site3/api/state`, `/site3/api/audio` — новая таблица `million_store` и отдельные пользовательские аудиофайлы.

## Установка поверх текущего Linux-сервера

**Сначала сохраняй свои изменения в GitHub; `install.sh` устанавливает код на сервер, а не загружает его в GitHub.**

```bash
# Если архив распакован в ~/million-v9-github:
sudo bash ~/million-v9-github/install.sh
```

Установщик проверяет окружение, делает резервную копию базы и файлов, добавляет (если отсутствует) таблицу `million_store` и проверяет оба сайта. Пароли из `/var/lib/games-local/` и пользовательские аудиофайлы не переписываются.

## Два пароля администратора

`/site3/` поддерживает прежний пароль и **дополнительный пароль из отдельного файла**. Значения в исходники GitHub не записываются.

- Основной: `ADMIN_KEY_FILE` (по умолчанию `/var/lib/games-local/admin.key`).
- Дополнительный: `ADMIN_EXTRA_KEY_FILE` (по умолчанию `/var/lib/games-local/admin-extra.key`).
- Если файла дополнительного пароля нет, работает только основной.
- В `/site2/` остаётся только прежняя авторизация, как и раньше.

Если второй пароль уже был создан на сервере, установщик его сохранит. Чтобы задать другой самостоятельно:

```bash
sudo install -o games-local -g games-local -m 600 /dev/null /var/lib/games-local/admin-extra.key
sudo bash -c 'read -rsp "Новый дополнительный пароль: " p </dev/tty; echo; printf "%s\n" "$p" > /var/lib/games-local/admin-extra.key'
sudo systemctl restart games-local.service
```

Пароль вида `key2026` слишком короткий и угадываемый для публичного сайта: после проверки рекомендуется более длинный.

## Публикация на GitHub

Распакуй ZIP, создай пустой репозиторий на GitHub и загрузи содержимое корневой папки (не ZIP как единственный файл). Или через `git init`, `git add .`, `git commit`, `git remote add origin ...`, `git push`.

**Не публикуй:** `games.sqlite`, `admin.key`, `admin-extra.key`, `.env`, `backups/`, пользовательские загруженные MP3. Для этого есть `.gitignore`.

В комплекте синтезированные звуки и лицензия Rubik. Исходный файл `million-intro.mp3` отсутствует: происхождение и права на его публичное распространение не подтверждены; на работающем сервере он сохраняется (установщик не удаляет старые файлы).

## Проверка после установки

```bash
systemctl is-active games-local.service
curl -s -o /dev/null -w '%{http_code}\n' http://127.0.0.1:8082/site3/api/million
curl -s -o /dev/null -w '%{http_code}\n' http://127.0.0.1:8082/site3/audio/intro.mp3
```

Открой `https://ТВОЙ-ДОМЕН/site3/` и перезагрузи страницу без кеша (`Ctrl+Shift+R`). Браузер запускает музыку после первого нажатия, а не самопроизвольно.

## Файлы

- `server.mjs` — Node HTTP адаптер для `/site2` + `/site3`.
- `million-worker.mjs` — API игры и авторизация двух паролей.
- `public/million/` — HTML/CSS/JS, шрифты, звуки, пример сценария.
- `install.sh` — безопасная установка поверх текущей службы.
- `.env.example` — пути для переменных среды без реальных значений.
